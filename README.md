# ML_task_04

В ходе работы были обучены и сравнены две модели линейной регрессии: базовая модель, использующая все доступные числовые признаки, и сокращённая модель, в которой были исключены признаки с высокой корреляцией между собой.

Для выявления мультиколлинеарности была построена корреляционная матрица. Дополнительно был рассчитан показатель VIF, позволяющий оценить степень линейной зависимости каждого признака от остальных.

Качество моделей оценивалось с помощью коэффициента детерминации R², средней абсолютной ошибки MAE и корня из средней квадратичной ошибки RMSE на одной и той же тестовой выборке.

                              	R2	      MAE	        RMSE	  Количество признаков
Базовая: все признаки	        0.0469	85822.4373	229134.2077	          4
Сокращённая: меньше признаков	0.0469	85822.4373	229134.2077	          4

По результатам сравнения сокращённая модель сохранила сопоставимое качество относительно базовой модели. При выборе финального набора признаков учитывались не только метрики, но и наличие мультиколлинеарности, а также содержательная значимость признаков.

График остатков показал наличие систематического паттерна. Это позволяет сделать предварительный вывод о возможном нарушении предположений линейной регрессии.

Таким образом, финальным был выбран набор признаков 'Period', 'Magnitude', 'Series_title_4', 'Series_title_5', поскольку остальные признаки влияют на результат незначительно
